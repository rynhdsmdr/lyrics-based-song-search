🎵 Ambatusing

Project Tugas Akhir Mata Kuliah Penelusuran Informasi

📘 Deskripsi

Ambatusing adalah sebuah aplikasi web yang memungkinkan pengguna untuk meng-input lirik lagu, kemudian sistem akan melakukan pencarian judul lagu yang paling relevan berdasarkan input tersebut.
Setelah proses pencarian selesai, aplikasi akan menampilkan 10 hasil teratas, lengkap dengan cover lagu.
Pengguna juga dapat melihat lirik lengkap melalui tombol "Lihat Lirik".

🛠️ Teknologi yang Digunakan

HTML – struktur halaman web

CSS – tampilan dan styling

Python – logika pemrosesan

Flask – backend dan routing aplikasi

📦 Instalasi & Cara Menjalankan

Clone repository:

git clone https://github.com/username/ambatusing.git
cd ambatusing


Install dependencies:

pip install -r requirements.txt


Jalankan aplikasi:

python app.py


Buka di browser:

http://localhost:5000
